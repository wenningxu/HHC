# 从生成旋转初始化的位置一致性优化

2026-10-07。用户强调从生成旋转开始优化；本次迭代实验已按此实现，区别于早先直接对齐骨骼方向的解析IK。

## 方法

- 对原生成6D按正确交错列布局解码为合法旋转矩阵R0；残差轴角delta全部初始化为0，局部旋转为exp(delta)R0。代码assert初始矩阵逐元素等于R0，不使用解析IK的局部解作为初值。
- 原位置、速度、接触通道保持逐元素不变；叶节点局部旋转保留原始6D。输出只更新非叶节点旋转。
- 损失=关节FK位置均方误差（m²）+0.02×修正轴角平方+0.01×相邻帧修正差平方。Adam lr0.01、60步，返回目标最小的迭代；两baseline同参数，不用FID作为优化目标。
- 官方表示未输出root旋转；从位置骨盆的三个子骨骼方向拟合root朝向，并固定。其余局部旋转严格从生成旋转开始。
- 不给生成拟合提供GT位置、旋转或betas。使用female零shape模板的骨骼方向，每段各自位置估计平均骨长。因此FK残差只是此估计骨架的一致性指标，不是已知真实SMPL shape下的误差。
- 时间项约束相对原生成的修正，不强制抹平原动作。生成与对应GT分别单独处理；GT处理只作自检，生成FID始终对原始未处理GT计算。

## 验证

自检覆盖零残差初始矩阵完全一致、反向骨骼旋转、模板FK往返、损失/梯度有限、未修改位置/速度/contact、叶旋转保留；完整验证480条固定请求、seed20261006生成缓存、CPU2、原版InterCLIP。

8条pilot两模型session1269/4014均exit0；GT平均局部旋转改动0.838°，FK残差19.58→2.10mm。InterMask FK133.20→40.56mm、InterGen33.51→7.08mm；小样本FID略降仅作管线检查，不能当完整结论。

完整480主句柄：InterMask28807、InterGen40156，均exit_code=0，用时311/313秒；结果分别为`output/intermask_generation_rotation_20261006/ik_initialized480.json`和`output/intergen_generation_rotation_20261006/ik_initialized480.json`。

结论：从生成旋转初始化的优化确实改善两个模型在估计骨架下的位置—旋转一致性；InterGen同时改善FID，InterMask则FID变差且帧间角变化增大。不能把“贴合预测位置”自动等同于真实旋转质量提高，也不能把InterGen单seed验证收益当正式显著提升。该FK残差不是对GT位置的MPJPE。未自动替换任何baseline正式输出或训练。
